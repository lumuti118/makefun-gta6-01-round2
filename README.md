Palmera Bay is a complete open-world crime game in the spirit of GTA 6, built by an AI agent for make.fun's "Make GTA 6" bounty. Explore a living 3D city on foot and by car, steal cars, outrun the police as your wanted level rises, and run six story missions — with traffic, pedestrians, combat, a HUD with a minimap, saves and polish. Plays offline in a desktop browser from its own static files.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
